## 已知限制（发布时逐条确认）

1. **浏览器人工回归**（BM-V1-905）：Chrome/Edge/Firefox 桌面+窄屏、鼠标+键盘路径需在目标部署网络执行；三个搜索目标（google/bing/baidu）可达性与编码在部署网络复验。
2. **Docker 镜像构建与漏洞扫描**（BM-V1-801）：需在发布环境 `docker build` + trivy 扫描；基础镜像 digest pin 按 Dockerfile 注释执行。
3. **真实调度与异机副本**（BM-V1-806）：连续两次 cron 备份成功与对象存储上传需在发布环境观察两个周期；异机副本口令经环境变量注入。
4. **RC 发布演练**（BM-V1-803）：全新部署/上一版本升级/迁移失败中止三条路径在演练环境执行并留档。
5. **恢复演练**（BM-V1-807/907）：容器重建、主机重启、ready 状态恢复在发布环境执行；恢复后登录、分类树、标签、回收站计数抽样与备份前一致。
6. **标签名含逗号/反斜杠的 HTML 往返**：CSV 无损；Netscape HTML TAGS 属性按逗号分隔（浏览器兼容），此类标签经 HTML 往返会按多标签解析（本系统导出/导入建议使用 CSV）。

## 备份与恢复

- 备份位置：`/opt/bookmark/backups`（bind 挂载，uid 10001）；每日/周/月 cron（deploy/cron-backup.example）；
- 异机副本：rclone/对象存储挂载 + 可选 AES-256 加密（口令文件 `/etc/bookmark/backup-key`，0600）；
- 恢复步骤与回滚：运维手册 §5/§9。
